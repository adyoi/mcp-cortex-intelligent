Overview

Cortex Intelligent is an MCP server that augments an ordinary LLM with context, procedures, memory, exemplars, verification, and an internal decision engine. Everything runs locally. No API keys, no cloud, no model gateway. The model becomes smarter by following structured guardrails and checking real execution feedback.

It is a standard MCP server (stdio transport), compatible with OpenCode, Claude Desktop, Cursor, VS Code, and any MCP client.

Auto-Provision Agent & Skill

Idempotent marker-block append. Never overwrites user content. Backup before write.

Model Awareness + Guardrails

Detects model tier (weak/medium/strong) and injects anti-blunder procedures.

Offline Cognitive Augmentor

Exemplar retrieval, structured self-critique, compliance scoring, verification runner.

Internal Decision Engine

Fast deterministic decisions (tier/risk/route/compliance) via heuristics. No LLM.

Plan & Task Management

AGENT → SKILL → PLAN → TASK ↔ EXECUTE → DONE. Persistent task tracking.

Knowledge Base + Memory

Hybrid search (BM25 + vector + RRF), long-term memory with decay.

Workflow

Bootstrap Session

  1. Call bootstrap_session(project_root).
  2. Detect model → model_decision → set session state.
  3. Provision agent & skill (append if exists).
  4. Inject guardrails via get_guardrails(task="session_start").

Task Execution

  1. get_guardrails(task_type) → checklist.
  2. retrieve_exemplars(task) → best examples.
  3. Plan → Read → Edit → Verify → Review.
  4. run_verification() → real feedback.
  5. score_compliance(plan) + self_critique(artifact).

Plan & Task Loop

  1. init_plan + init_task.
  2. Agent reads PLAN.md → picks next task.
  3. task_list(status="todo") → choose.
  4. task_start(id) → doing.
  5. Execute with guardrails + verification.
  6. task_done(id) after verification passes.
  7. task_sync_md() → write TASK.md.

Security

  • Secrets are never stored (no-secret rule).
  • Verification runner uses allowlist, locked cwd, timeout, minimal env.
  • Provisioning restricted to .opencode/ under project root.
  • Backup before overwrite; idempotent writes.
  • 100% offline, no network calls.

Troubleshooting

Tools not showing up

Check config filename (opencode.json), location (global: ~/.config/opencode/opencode.json), cwd, and CORTEX_DB_DIR. Restart OpenCode.

Slow first start

tsx compiles TypeScript on first run; subsequent calls are fast. Use compiled dist/ entry.

Verification runner blocked

Only allowlisted commands run. Adjust CORTEX_VERIFY_ALLOWLIST.
